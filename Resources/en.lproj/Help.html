Simple Sync S3 (S5)

Automatically uploads folders from your Mac to an Amazon S3 bucket. One-way sync (Mac → S3), at regular intervals and/or at fixed times, from the menu bar.

1. Install

Requirements: macOS 13 or later, and Apple's developer tools (xcode-select --install if Xcode is not installed).

git clone https://github.com/jerry42/simple-sync-s3.git
cd simple-sync-s3
./scripts/install.sh            # standard version
./scripts/install.sh --sandbox  # or: App Sandbox version

The script builds the app, quits the running copy if there is one, copies it to /Applications/Simple Sync S3.app and launches it. A cloud icon appears in the menu bar (no Dock icon).

The app used to be called MyDropbox. If that version is installed, the script quits and removes it; on first launch, Simple Sync S3 takes over its configuration, sync cache and Keychain secret key. macOS asks once more for folder access (it sees a new app). The sandboxed version starts with an empty configuration.

On first launch, the app creates a configuration template and shows “Configuration needs fixing”.

The interface and this help follow the macOS language: French if the system is in French, English otherwise. To change the language of this app only: System Settings → General → Language & Region → Applications.

You can always edit config.json by hand (menu Open config.json, then Reload Configuration, ⌘R): the settings window keeps the keys it does not show.

2. Configure

  1. Menu ☁︎ → Settings… (⌘,).
  2. AWS Account tab: profile (the “Profiles” menu lists those in ~/.aws) or access key, bucket, region.
  3. Sync tab: interval, fixed times, deletions on S3, launch at login.
  4. Folders tab: “+” opens a folder picker; for each folder, S3 prefix and exclusions (one per line). JSON mode lets you paste or edit the raw list.
  5. Save (⌘S): the configuration is checked, written to config.json and reloaded.
  6. Menu → Sync Now (⌘S) for a first try, then Open Log.
{
  "awsProfile": "default",
  "region": "eu-west-3",
  "bucket": "my-bucket",
  "deleteRemote": false,
  "launchAtLogin": true,
  "schedule": { "intervalMinutes": 60, "dailyTimes": ["02:00"], "syncOnLaunch": true },
  "folders": [
    { "localPath": "~/Documents/Invoices", "s3Prefix": "invoices", "exclude": ["*.tmp", "node_modules/"] }
  ]
}
KeyMeaning
bucketS3 bucket name (required).
regionBucket region, for example eu-west-3. Optional with a profile that declares it in ~/.aws/config.
awsProfileAWS profile (see below). If omitted: default, unless accessKeyId is set.
accessKeyId, secretAccessKey, sessionTokenAWS access key, instead of the profile or as a fallback.
deleteRemotetrue: a file deleted from the Mac is also deleted from S3. false by default.
launchAtLogintrue: the app starts at login.
scheduleWhen to sync (see Schedule).
foldersFolders to upload (see Folders).

3. AWS credentials

Three ways, pick one. IAM permissions needed on the bucket: s3:ListBucket, s3:PutObject, and s3:DeleteObject if deleteRemote is on.

A. An AWS profile (~/.aws)

"awsProfile": "my-profile". Profiles with keys (aws_access_key_id / aws_secret_access_key) and IAM Identity Center (SSO) profiles are handled by the app itself. The standard version can also use credential_process and the AWS CLI (assume-role…).

SSO profile: when the session has expired, menu → Sign In to AWS…. Your browser opens with the code pre-filled (it is also shown in the menu): approve it, that's all. The session is shared with the AWS CLI (an aws sso login done elsewhere counts too) and renews itself as long as the IAM Identity Center session is valid.

B. An access key, secret key in the Keychain (recommended without a profile)

"accessKeyId": "AKIA…",
"region": "eu-west-3",

Reload the configuration, then menu → Save AWS Secret Key… and paste the secret key. It is stored in the macOS Keychain, never in a file.

C. Access key and secret key in config.json

"accessKeyId": "AKIA…",
"secretAccessKey": "…",
"region": "eu-west-3",

The simplest, but the secret key is stored in plain text in the file (~/Library/Application Support/SimpleSyncS3/config.json, readable by your account only). If the Keychain also holds a secret key for the same access key, the Keychain one is used. For temporary credentials, add "sessionToken".

With awsProfile and accessKeyId, the profile comes first and the access key is the fallback. The source used is written to the log at every sync (shortened access key, never the secret key).

4. Folders and exclusions

KeyMeaning
localPathFolder on the Mac. ~ = your home folder.
s3Prefix“Subfolder” in the bucket. Default: the local folder's name. "" = bucket root.
excludePatterns to skip, as in a .gitignore.
PatternEffect
*.tmpAll .tmp files, at any depth.
node_modules/node_modules folders and their content.
/draftsOnly drafts at the root of the folder.
docs/**/*.pdfPDFs in docs and its subfolders.
!important.logRe-includes a file excluded by an earlier pattern.

.DS_Store and ._* files are always skipped.

A file is uploaded if it is missing from S3 or if it changed. Files already identical on S3 are not uploaded again. Files over 5 GB: skipped for now.

Deletions (deleteRemote): never with an empty prefix (whole bucket), never if the local folder is empty or missing (unplugged drive), and never for an excluded file.

5. Schedule

KeyMeaning
intervalMinutesSync every N minutes (omitted or 0: off).
dailyTimesFixed times "HH:mm". A time missed while the Mac was asleep is caught up on wake.
syncOnLaunchSync when the app starts.

During a sync, the first line shows the current folder, the percentage and the number of files processed (e.g. “Dropbox: 37% (1250 / 3400)”). The icon changes during a sync, and shows an exclamation mark when there is an error.

7. Sandboxed version

Installed with ./scripts/install.sh --sandbox, the app is confined by macOS: it only sees the folders you show it.

  • The menu shows “Folders needing access: N”. Click Grant Access…: for each folder, a panel opens already pointing at it; click Allow. Only once. A folder added with “+” in the settings is granted directly.
  • ~/.aws is only requested if you use a profile.
  • credential_process and the AWS CLI are not available: use a profile with keys, an SSO profile, or an access key.
  • Its files are kept apart, in ~/Library/Containers/com.jerry42.SimpleSyncS3/Data/Library/ (configuration in Application Support/SimpleSyncS3, log in Logs/SimpleSyncS3). The standard version's configuration is not taken over: copy it, or use “Settings…”.

8. Troubleshooting

Always start with Open Log: every sync writes the credential source and the reason for each error there.

MessageWhat to do
Configuration needs fixingThe message names the key at fault (bucket, folder, badly written time, JSON comma…).
IAM Identity Center sign-in requiredMenu → Sign In to AWS…
No secret key for access keyMenu → Save AWS Secret Key…, or secretAccessKey in config.json.
Unknown AWS regionAdd "region" to config.json.
S3 HTTP 403 – AccessDeniedInsufficient IAM permissions on the bucket, or wrong account.
S3 HTTP 301 / PermanentRedirectThe region does not match the bucket's region.
Access not granted (sandbox)Menu → Grant Access…
macOS asks again for access to Documents or the Keychain after an updateThe app is signed “ad hoc”. Once: ./scripts/create-signing-cert.sh then ./scripts/install.sh; permissions are then kept from one version to the next.

Test without the interface, with a separate configuration:

swift run s5-sync --config ~/s5-test/config.json [--login]

9. Uninstall

  1. Set "launchAtLogin": false, reload the configuration, then quit the app.
  2. Delete /Applications/Simple Sync S3.app.
  3. Optional: ~/Library/Application Support/SimpleSyncS3, ~/Library/Logs/SimpleSyncS3, ~/Library/Containers/com.jerry42.SimpleSyncS3 (sandboxed version), and the “SimpleSyncS3” Keychain item. After an upgrade from the former name, the same “MyDropbox” items can be deleted too.

Uninstalling never deletes anything from S3.
