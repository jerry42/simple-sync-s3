Simple Sync S3 (S5)

Envoie automatiquement des dossiers de ton Mac vers un bucket Amazon S3. Synchro à sens unique (Mac → S3), à intervalle régulier et/ou à heures fixes, depuis la barre des menus.

1. Installer

Prérequis : macOS 13 ou plus récent, et les outils de développement Apple (xcode-select --install si Xcode n'est pas installé).

git clone https://github.com/jerry42/simple-sync-s3.git
cd simple-sync-s3
./scripts/install.sh            # version standard
./scripts/install.sh --sandbox  # ou : version App Sandbox

Le script compile l'app, quitte la version en cours s'il y en a une, la copie dans /Applications/Simple Sync S3.app et la lance. Une icône de nuage apparaît dans la barre des menus (pas d'icône dans le Dock).

L'app s'appelait auparavant MyDropbox. Si cette version est installée, le script l'arrête et la retire ; au premier lancement, Simple Sync S3 reprend sa configuration, son cache de synchro et la clé secrète du trousseau. macOS redemande une fois l'accès aux dossiers (nouvelle app pour lui). La version sandbox repart d'une configuration vide.

Au premier lancement, l'app crée un modèle de configuration et affiche « Configuration à corriger ».

On peut toujours modifier config.json à la main (menu Ouvrir config.json, puis Recharger la configuration, ⌘R) : les réglages conservent les clés qu'ils n'affichent pas.

2. Configurer

  1. Menu ☁︎ → Réglages… (⌘,).
  2. Onglet Compte AWS : profil (le menu « Profils » liste ceux de ~/.aws) ou clé d'accès, bucket, région.
  3. Onglet Synchro : intervalle, heures fixes, suppressions sur S3, lancement à l'ouverture de session.
  4. Onglet Dossiers : « + » ouvre un sélecteur de dossiers ; pour chacun, préfixe S3 et exclusions (une par ligne). Le mode JSON permet de coller ou d'éditer la liste brute.
  5. Enregistrer (⌘S) : la configuration est vérifiée, écrite dans config.json et rechargée.
  6. Menu → Synchroniser maintenant (⌘S) pour un premier essai, puis Ouvrir le journal.
{
  "awsProfile": "default",
  "region": "eu-west-3",
  "bucket": "mon-bucket",
  "deleteRemote": false,
  "launchAtLogin": true,
  "schedule": { "intervalMinutes": 60, "dailyTimes": ["02:00"], "syncOnLaunch": true },
  "folders": [
    { "localPath": "~/Documents/Factures", "s3Prefix": "factures", "exclude": ["*.tmp", "node_modules/"] }
  ]
}
CléRôle
bucketNom du bucket S3 (obligatoire).
regionRégion du bucket, par exemple eu-west-3. Facultatif avec un profil qui la déclare dans ~/.aws/config.
awsProfileProfil AWS (voir ci-dessous). Absent : default, sauf si accessKeyId est renseigné.
accessKeyId, secretAccessKey, sessionTokenClé d'accès AWS, à la place ou en secours du profil.
deleteRemotetrue : un fichier supprimé du Mac est aussi supprimé de S3. false par défaut.
launchAtLogintrue : l'app démarre à l'ouverture de session.
scheduleQuand synchroniser (voir Planification).
foldersDossiers à envoyer (voir Dossiers).

3. Identifiants AWS

Trois façons, au choix. Droits IAM nécessaires sur le bucket : s3:ListBucket, s3:PutObject, et s3:DeleteObject si deleteRemote est activé.

A. Un profil AWS (~/.aws)

"awsProfile": "mon-profil". Profils à clés (aws_access_key_id / aws_secret_access_key) et profils IAM Identity Center (SSO) sont gérés directement par l'app. La version standard sait aussi utiliser credential_process et l'AWS CLI (assume-role…).

Profil SSO : quand la session a expiré, menu → Se connecter à AWS…. Le navigateur s'ouvre avec le code pré-rempli (il s'affiche aussi dans le menu) : valide, c'est tout. La session est partagée avec l'AWS CLI (un aws sso login fait ailleurs compte aussi) et se renouvelle seule tant que la session IAM Identity Center est valable.

B. Une clé d'accès, clé secrète dans le trousseau (recommandé sans profil)

"accessKeyId": "AKIA…",
"region": "eu-west-3",

Recharge la configuration, puis menu → Enregistrer la clé secrète AWS… et colle la clé secrète. Elle est rangée dans le trousseau macOS, jamais dans un fichier.

C. Clé d'accès et clé secrète dans config.json

"accessKeyId": "AKIA…",
"secretAccessKey": "…",
"region": "eu-west-3",

Le plus simple, mais la clé secrète est en clair dans le fichier (~/Library/Application Support/SimpleSyncS3/config.json, lisible par ton seul compte). Si une clé secrète existe aussi dans le trousseau pour la même clé d'accès, c'est celle du trousseau qui sert. Pour des identifiants temporaires, ajoute "sessionToken".

Avec awsProfile et accessKeyId, le profil passe en premier et la clé d'accès sert de secours. La source utilisée est écrite dans le journal à chaque synchro (clé d'accès abrégée, jamais la clé secrète).

4. Dossiers et exclusions

CléRôle
localPathDossier du Mac. ~ = ton dossier personnel.
s3Prefix« Sous-dossier » dans le bucket. Par défaut : le nom du dossier local. "" = racine du bucket.
excludeMotifs ignorés, comme dans un .gitignore.
MotifEffet
*.tmpTous les fichiers .tmp, à toute profondeur.
node_modules/Les dossiers node_modules et leur contenu.
/brouillonsSeulement brouillons à la racine du dossier.
docs/**/*.pdfLes PDF de docs et de ses sous-dossiers.
!important.logRé-inclut un fichier exclu par un motif précédent.

.DS_Store et les fichiers ._* sont toujours ignorés.

Un fichier est envoyé s'il manque sur S3 ou s'il a changé. Les fichiers déjà identiques sur S3 ne sont pas renvoyés. Fichiers de plus de 5 Go : ignorés pour l'instant.

Suppressions (deleteRemote) : jamais avec un préfixe vide (tout le bucket), jamais si le dossier local est vide ou introuvable (disque débranché), et jamais pour un fichier exclu.

5. Planification

CléRôle
intervalMinutesSynchro toutes les N minutes (absent ou 0 : désactivé).
dailyTimesHeures fixes "HH:mm". Une heure manquée pendant la veille est rattrapée au réveil.
syncOnLaunchSynchro au démarrage de l'app.

7. Version sandbox

Installée avec ./scripts/install.sh --sandbox, l'app est enfermée par macOS : elle ne voit que les dossiers que tu lui montres.

  • Le menu indique « Accès à autoriser : N dossier(s) ». Clique Autoriser l'accès… : pour chaque dossier, un panneau s'ouvre déjà placé dessus ; clique Autoriser. À faire une seule fois. Un dossier ajouté avec « + » dans les réglages est autorisé directement.
  • ~/.aws n'est demandé que si tu utilises un profil.
  • credential_process et l'AWS CLI ne sont pas disponibles : utilise un profil à clés, un profil SSO, ou une clé d'accès.
  • Ses fichiers sont à part, dans ~/Library/Containers/com.jerry42.SimpleSyncS3/Data/Library/ (configuration dans Application Support/SimpleSyncS3, journal dans Logs/SimpleSyncS3). La configuration de la version standard n'est pas reprise : recopie-la, ou passe par « Réglages… ».

8. En cas de problème

Commence toujours par Ouvrir le journal : chaque synchro y écrit la source des identifiants et la raison de chaque erreur.

MessageQue faire
Configuration à corrigerLe message indique la clé en cause (bucket, dossier, heure mal écrite, virgule JSON…).
Connexion IAM Identity Center requiseMenu → Se connecter à AWS…
Aucune clé secrète pour la clé d'accèsMenu → Enregistrer la clé secrète AWS…, ou secretAccessKey dans config.json.
Région AWS inconnueAjoute "region" dans config.json.
S3 HTTP 403 – AccessDeniedDroits IAM insuffisants sur le bucket, ou mauvais compte.
S3 HTTP 301 / PermanentRedirectLa région ne correspond pas à celle du bucket.
Accès non autorisé (sandbox)Menu → Autoriser l'accès…
macOS redemande l'accès à Documents ou au trousseau après une mise à jourL'app est signée « ad hoc ». Une seule fois : ./scripts/create-signing-cert.sh puis ./scripts/install.sh ; les autorisations sont ensuite gardées d'une version à l'autre.

Test sans l'interface, avec une configuration à part :

swift run s5-sync --config ~/s5-test/config.json [--login]

9. Désinstaller

  1. Mets "launchAtLogin": false, recharge la configuration, puis quitte l'app.
  2. Supprime /Applications/Simple Sync S3.app.
  3. Facultatif : ~/Library/Application Support/SimpleSyncS3, ~/Library/Logs/SimpleSyncS3, ~/Library/Containers/com.jerry42.SimpleSyncS3 (version sandbox), et l'élément « SimpleSyncS3 » du trousseau. Après un passage depuis l'ancien nom, les mêmes éléments « MyDropbox » peuvent aussi être supprimés.

Rien n'est jamais supprimé de S3 par la désinstallation.
